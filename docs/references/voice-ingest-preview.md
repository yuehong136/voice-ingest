# Voice Ingest preview research

The preview reuses the [first-round product research](agensi-pilot-r1.md) and the [second-round editor and client tests](../plans/agensi-pilot-r2.md). It revisits the sources that affect someone trying the package from a clean environment. The implementation starts from `acf8120` plus the local pilot changes. This checkout resolves FastMCP `4.0.2` and Playwright `1.63.0`.

| Reference | Problem and prerequisite | Decision and evidence |
| --- | --- | --- |
| [Descript subtitle export](https://help.descript.com/export-and-share/subtitles) · [Riverside Magic Clips](https://riverside.com/magic-clips) | Descript starts from a transcript and offers a subtitle deliverable. Riverside surfaces suggested clips from a recording. Both begin with material already processed by the product. | Adapt the direct path from a visible candidate to its source quote, interval and download. Use an offline example independent of service setup. Product signup-to-result latency and recovery remain unmeasured. |
| [Agent Skills specification](https://agentskills.io/specification) · [Agensi file loading](https://www.agensi.io/docs/how-agents-load-skills) | Start with the Skill instructions and request only the needed assets. An explicit SRT input or a pasted transcript is required. | Adopt the package layout and simulate file retrieval using a local fixture. Test the release ZIP in an empty directory. Live platform OAuth and delivery remain unverified. |
| [Agent Skills evaluation guide](https://agentskills.io/skill-creation/evaluating-skills) · WhisperX `v3.8.6` [alignment code](https://github.com/m-bain/whisperX/blob/v3.8.6/whisperx/alignment.py) and [timestamp tests](https://github.com/m-bain/whisperX/blob/v3.8.6/tests/test_word_timestamp_interpolation.py) | Use realistic prompts in a paired comparison. The alignment tests exercise missing and exceptional timing around known words. A synthetic fixture can establish the expected ranges and failures. | Adapt the evaluation method and timestamp cases to the SRT/JSON and clip handoff contracts. Keep the existing ASR. The [comparison](../../tests/clip_eval/README.md) uses three synthetic cases. Editor preference on real material remains unverified. |
| [Playwright video recording](https://playwright.dev/docs/videos) · [Playwright 1.63.0](https://github.com/microsoft/playwright/tree/v1.63.0) | Capture the sample in a browser and verify that a downloaded page works with networking disabled. The capture needs a browser installation. | Reuse the locked version for capture and Chromium checks. Add audio from the two matching local source windows. No confirmed need for a dependency upgrade. |
| KittenTTS `0.9.8` [ONNX dispatch](https://github.com/KittenML/KittenTTS/blob/5802f6b956844919ecf210f4e55f4750a6ad7c6f/kittenml/get_model.py) and [local tests](https://github.com/KittenML/KittenTTS/blob/5802f6b956844919ecf210f4e55f4750a6ad7c6f/tests/test_kittentts2_tiny.py) | Generate reproducible example speech from authored lines with the bundled voices. Requires pinned English weights, voice profiles and pronunciation assets. | Use the CPU int8 path in the example generator with the two model revisions recorded in the asset manifest. Keep generation outside the application dependencies. |

Additional editor import, waveform navigation and library upgrades stay deferred until a first run shows which step needs them.
